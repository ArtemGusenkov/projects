# Анализ розничных продаж

Аналитический проект на данных The Complete Journey

## Цель проекта 

Изучить, что влияет на изменение продаж, как меняется активность покупателей, какие закономерности наблюдваются во время проведения акций

## Данные

датасет (The Complete Journey), который содержит покупки 2500 домохозяйст за два года

## стек

postgres, superset, python

## основные результаты

Продажи

С начала проведения эксперимента продажи по неделям вырасли в среднем с 83 тыс. $ до 88 тыс. $.
Рост выручки не связан с количеством покупателей или количеством посещений магазинов. За все время наблюдений выросло количество продаваемых товаров. Основной прирост количества продаваемы товаров пришелся на категорию продуктов питания (groceries). В процентном соотношении рост доля продуктов питания в покупках практически не меняется со временем, что может говорить росте продаж товаров и других категорий.
