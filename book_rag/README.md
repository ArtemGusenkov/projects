# Sherlock Holmes books RAG

Поиск ответов на вопросы по книгам о Шерлоке Холмсе  
Поиск осуществляется по книгам в fb2 формате, ответы формируются вместе с ссылками на конткретные отрывки  

## Структура

```
fb2_parser.py   обработка файлов книг
vectors_bd.py   разделение на чанки, создание и загрузка векторов в коллекцию qdrant
db_search.py    поиск по вопросу симантически близких чанков и формирование ответа
main.py         приложение
```

## запуск

```
uv run main.py "вопрос"
```
