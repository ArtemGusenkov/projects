# Sherlock Holmes books RAG

Поиск ответов на вопросы по книгам о Шерлоке Холмсе  
Поиск осуществляется по книгам в fb2 формате, ответы формируются вместе с ссылками на конткретные отрывки  

## Структура

```
src/fb2_parser.py       обработка файлов книг
src/vectors_bd.py       разделение на чанки, создание и загрузка векторов в коллекцию qdrant
src/retrieval.py        поиск по вопросу похожих чанков 
src/answer_forming.py        формирование ответа на вопрос на основе переданных чанков
src/golden_dataset_generator.py        генерация эталонных вопросов с ответами для оценки качества метрик
src/evaluation.py       оценка метрик на эталлоном датасете
src/main.py             приложение

eval_dataset/           сгенерированный набор эталонных вопросов с ответами

eval_result/            метрики качества 
```

## запуск

```
uv run main.py "вопрос"
```
