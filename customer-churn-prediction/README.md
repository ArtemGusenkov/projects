# Предсказание оттока пользователей

## О проекте
Данный проект посвящен прогнозированию оттока клиентов банка

Цель проекта - построить модель, которая сможет заранее выявлять клиентов, собирающихся отказаться от услуг банка. 
Это позволит банку своевременно реагировать на отток клиентов - предлагать персональные условия для клиентов, тем самым удерживая своих клиентов

---

## Бизнес-задача

Отток клиентов (Customer Churn) - это показатель, отражающий количество клиентов, которые перестают пользоваться услугами компании 

Отток клиентов - важный показатель, поскольку в отрослях с высокой конкуренцией удержание существующих клиентов обходится дешевле, чем привлечение новых

<!-- По этой причине компаниям важно заранее определять клиентов с высоким риском ухода и своевременно принимать меры по их удержанию.

Индивидуальное удержание клиентов - сложная задача, поскольку большинство компаний имеют большое количество клиентов и не могут позволить себе уделять много времени каждому из них.

Однако, если корпорация сможет заранее спрогнозировать, какие клиенты, скорее всего, уйдут, она сможет сосредоточить усилия по удержанию клиентов только на этих «клиентах высокого риска». Конечная цель - расширение зоны покрытия и восстановление лояльности клиентов. -->

Цель проекта

Построить модель для прогнозирования вероятности ухода клиента и определить наиболее значимые параметры, влияющие на отток

## Этапы проекта

- Разведочный анализ (EDA)
- Очистка данных
- Feature Engineering
- Кодирование категориальных признаков
- Масштабирование данных
- Борьба с дисбалансом классов (SMOTE)
- Обучение нескольких моделей
- Подбор гиперпараметров с помощью Optuna
- Интерпретация модели с использованием SHAP
- Сравнение результатов моделей

## Метрика качества

Основной метрикой оценки выбрана **ROC-AUC**
