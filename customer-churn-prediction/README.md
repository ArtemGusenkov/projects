# Предсказание оттока пользователей

## О проекте
Данный проект посвящен прогнозированию оттока клиентов банка

Цель проекта - построить модель, которая сможет заранее выявлять клиентов, собирающихся отказаться от услуг банка. 
Это позволит банку своевременно реагировать на отток клиентов - предлагать персональные условия для клиентов, тем самым удерживая своих клиентов

---

## Бизнес-задача

Отток клиентов (Customer Churn) - это показатель, отражающий количество клиентов, которые перестают пользоваться услугами компании 

Отток клиентов - важный показатель, поскольку в отрослях с высокой конкуренцией удержание существующих клиентов обходится дешевле, чем привлечение новых

## Этапы проекта

- Масштабирование данных

## Результаты  

355 190 размеченных строк, 114 исходных признаков, доля оттока 8,14%.

## Метрика качества

Основной метрикой оценки выбрана **ROC-AUC**

| модель | значение ROC-AUC |
| -- | --: |
| log.reg. (base line) | 0.72 |
| log.reg. (w preprocess) | 0.73 |
| lgbm | 0.84 |


## Основные выводы
